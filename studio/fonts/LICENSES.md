# Bundled fonts

These fonts are embedded in the `wecut` binary. Each keeps its own license; the code license of WeCut does not apply to them.

- The first thirteen families (Anton ... Roboto, 700 weights) are Latin subsets as served by Google Fonts.
- Fonts added in 0.3.0 come from the Google Fonts repository (github.com/google/fonts). Most were reduced to Latin and Latin Extended with fontTools (a Modified Version under the OFL; their names carry no Reserved Font Name). Families whose licence reserves their name ship as the unmodified original file, marked below.
